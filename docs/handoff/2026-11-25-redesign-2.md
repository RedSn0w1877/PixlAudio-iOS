# Redesign batch 2 (iOS), 2026-11-25

Branch `redesign-2` (cut from `everything`, `origin/everything` merged in for the ring-code build fix). The port of
Android's redesign batch 2 (Android branch `redesign-2`, `handoff/2026-11-25-redesign-2.md`, commits cbb72c8..bf115a5):
Android's layout, sizes, order, spacing and content, Material swapped for Liquid Glass. Not run on a phone: Hoa tests
the build.

## What changed

- **Kit** `App/DesignSystem/Components/RedesignKit.swift`: `Redesign` metrics, `PixlTextStyle.redesign*`,
  `RedesignScreenTitle`, `RedesignHeaderButton`, `RedesignFilterChip`, `GroupPosition` + `RedesignGroupButton`,
  `groupedRowShape`, `BadgeShapeKind` + `ExpressiveBadgeShape` + `ShapeBadge`, `RedesignSectionLabel`,
  `RedesignGroupedRow`. docs/design.md › Redesign batch 2 has the glass mapping.
- **Mini player** `MiniPlayerBar.swift`, `Tokens.MiniPlayer`: Cookie9 48 pt cover, bare previous / next, 48 pt play /
  pause, `MiniPlayerProgressLine` instead of `MiniPlayerProgressRing` (removed).
- **Library** `LibraryView.swift` (flat header, chips, compact pill kept), `LibraryActionRow.swift` (`LibraryToolsRow`
  replaces `LibraryActionRow`; `LibraryTabChips`; the selection row is unchanged), `LibraryPages.swift` (album grid tile;
  the list card keeps the album colours). The main action moved to the header (+ / Shuffle); Sort by stays a system
  menu, opened from the sort text button. Ids kept: `library.mainAction`, `library.sort`, `library.settings`,
  `library.tab.<Title>`, `library.tab.accessory`; new `library.locate`, `library.instrumentalFilter`,
  `library.view.list|grid`.
- **Search** `SearchView.swift` (header, Top result, spacing), `SearchHistoryViews.swift` (`SearchRecentRow`, Recent strip
  = 3 rows, focused list without a card; suggestions unchanged), `SearchFilterChips.swift` (connected group, new order),
  `SearchResultRows.swift` (section title, `SearchTopResultCard`), `GenreBrowseView.swift` ("Browse", 96 pt tiles with a
  shape picked by `JavaHash.of(id)` like Android's `hashCode`).
- **Queue** `QueueSheet.swift`: header (Save · Clear group, Up next line), `QueueNowPlayingCard`, grouped rows (pitch is
  measured on the first upcoming row), split-pill toolbar; the ⋯ menu and its morph, swipe, drag, undo, notes and the
  Autoplay line are unchanged (`SetNoteRowLabel` / `AutoplayLine` paddings reduced for the 16 pt gutter).
- **Ask Taizo** `TaisChatSheet.swift` (header always shown, empty page, `TaizoInputPills`, Recent chats square +
  New chat square), `TaizoViews.swift` (row layout, plain answers, `TaizoMixCard`, `TaizoShapeAvatar`,
  `TaizoOutlinedChip`, `WeightedRow`), `TaisChatModel.stop()`, `TaizoVoiceInput.swift` (Speech framework mic; asks for
  microphone + speech permission on the first tap — `project.yml` has the two usage strings; playback pauses while it
  listens, then the session goes back to `.playback` long-form and playback resumes). `TaizoOrb`, the mood chips and the
  greeting are no longer shown (code kept).
- **Settings** `SettingsView.swift` (own scroll view with the header, `SettingsAccountsCard`, `SettingsMainEntry.listening`
  / `.app`, `SettingsCategoryRow` on `RedesignGroupedRow`, Developer mode row with id `settings.switch.Developer mode`),
  `SettingsMetrics.rowInnerRadius` 4 / `groupRadius` 20, `SettingsSubsection` label 14/20 16 pt in.
  `SettingsFeatureTests.testMainListOrderMatchesAndroid` follows the new order.
- docs: parity.md › Redesign batch 2, design.md (mapping rows + Redesign batch 2).
