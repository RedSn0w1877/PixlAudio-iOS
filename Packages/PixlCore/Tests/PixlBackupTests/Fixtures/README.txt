Test fixtures for PixlBackupTests (bundled as Bundle.module, subdirectory "Fixtures").

All of them are generated by tools/android-reference/BackupGen.java from the Android app's compiled classes,
Gson 2.14 and the JDK's zip streams — regenerate them there instead of editing by hand:

- backup-android-golden.jsonl  {"fn","in","out"} vectors: format detection, sanitiser, module schema and manifest
                               validation, checksums, Gson binding of every module record, the legacy adapter, the
                               engagement merge, the playlist song resolver, Gson's pretty printer, archive reads.
- inflate-cases.jsonl          raw DEFLATE streams from java.util.zip.Deflater (levels 0/1/6/9, filtered,
                               Huffman-only, sync flushes) with the size and SHA-256 of the plain data.
- android-v3.pxpl              a v3 backup built like BackupWriter: "PXPL" + ZipOutputStream (DEFLATED entries
                               with data descriptors), every module filled.
- android-v3-stored.pxpl       the same format with STORED entries (what PixlBackup writes).
- android-v2-legacy.pxpl       a v2 backup built like AppDataBackupManager: "PXPL" + GZIPOutputStream of the JSON.
- android-v1-legacy.json.gz    a v1 backup (combined "preferences") gzip-compressed without the magic.
- android-v1-legacy.json       the same v1 backup as raw JSON.

The PixlBackup module name is kept in this file for the fixture-bundling smoke test.
