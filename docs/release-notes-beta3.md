# pixlaudio for ios, beta 2

ok this one is all about sound ngl. heres whats new since beta 1

## new stuff

- spatial audio is here ye. six profiles in a sheet right off the player, made for headphones. it plays a quick on-phone version straight away while the cloud makes the real one, and once a song is made it gets shared so it only ever has to be made once
- new "this song" switch in that sheet, turn spatial off for just one song and it plays the original at full quality. it remembers too
- spotiflac: songs try a flac file first now and fall back to youtube like before, so most songs sound way better
- audio quality has five levels now: low, medium, high, pro and studio pro. pro is the default (flac up to 48 kHz), studio pro takes the giant 96-192 kHz files too. low / medium / high stay on youtube to save data
- the player tells you which one is actually playing
- on youtube, iphones can play the better opus stream now when its ready

## changed

- if you had standard it moved to medium, ultrasound moved to pro
- when spatial is on, the cloud version is made from the flac you actually play

## fixed + faster

- flac downloads in pieces at the same time so it starts quicker
- the app checks a file before playing it so pro never accidentally grabs a giant file

## good to know

- spatial audio needs headphones by default
- studio pro files can be like 6 Mbps, so maybe not on mobile data lol
