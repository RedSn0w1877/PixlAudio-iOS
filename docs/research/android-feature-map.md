## 4. Android → iOS replacements
MediaStore/SyncWorker → folder bookmarks + Documents + MPMediaQuery (DRM-free) · Media3/ExoPlayer/audiofx → AVQueuePlayer decks + MTAudioProcessingTap, MPNowPlayingInfoCenter, MPRemoteCommandCenter · WorkManager → BGTaskScheduler / foreground work · EncryptedSharedPreferences → Keychain · DataStore → UserDefaults · Room → SwiftData (no FTS → in-memory index) · JsEvaluator WebView → JavaScriptCore · PoToken WebView → WKWebView · Glance/tiles → system Now Playing + App Intents · Wear → Apple Watch Now Playing · Android Auto → not possible (CarPlay entitlement) · Cast → AirPlay · TFLite/ONNX/MediaPipe → Core ML / Foundation Models · TagLib → own PixlTags + AVFoundation · AGSL → Metal via SwiftUI shaders · kyant backdrop → native `.glassEffect()`.

## 5. Risks
YouTube extraction violates YouTube ToS (fine for sideloading, never for App Store). Local files work very differently on iOS. Plus/checkout and the self-updater don't apply. Bundled models ~425 MB → download on demand. Long background jobs are limited on iOS. Ollama/custom AI endpoints need ATS exceptions.

## 6. Karaoke lyrics
Spec: `spec-lyricsView.md` in this folder (637 lines, written for Android/Compose — the iOS adaptation lives in the repo's docs/specs). Android files: `presentation/lyrics/{LyricsView.kt 877, LyricLineNode.kt 890, LyricsEngine.kt 1205, LyricsClock.kt, EmphasisMath.kt, InterludeTimeline.kt, InterludeDots.kt, LyricsAppearancePrefs.kt, model/*, background/{ArtworkSpriteBaker 332, LyricsArtworkBackground 574, LyricsBackgroundShader 241}}`; host `components/LyricsSheet.kt`; position `PlaybackStateHolder.framePositionMs()`.
Constants as implemented (code wins over spec where they differ):
- Springs (mass 0.9): normal ζ = 1.1/√0.9 ≈ 1.1595, stiffness = (170 + 50·ratio)/0.9, ratio = (1 − (clamp(gap,100,800) − 100)/700)^0.2; slow (seek/snap-back) web (0.9, 90, 15) → ζ 0.833, k 100; ended web (0.9, 140, 22); scale web (2, 100, 25) → ζ 0.884, k 50; background vocals ζ 0.9, k 150.
- Timing: lead-in 250 ms; activeness rise 300 ms / fall 450 ms, cubic(0,0,0.58,1); inactive scale 0.97 only while playing.
- Blur: σ = min(5, (1 + d)·0.8) × strength; tween 400 ms (250 ms dragging); radius quantum 1.5 px on Android (0.25 caused churn) — recalibrate for SwiftUI `.blur`.
- Cascade: base step 50 ms, `step /= 1.05` from the target row; rows beyond ±300 dp snap; first show starts at 2 × viewport height.
- Alpha: inactive 0.20; active unsung max(0.35, inactive + 0.10) (bright art: 0.50→0.60); sung 1.0; background vocals 0.175/0.35; translation 0.45/0.20; press highlight 0.07; bright art inactive 0.50 + 0.35 scrim; high contrast inactive 0.55.
- Word fill: soft edge 0.5 × line height, edge centre L − fade/2 → R + fade/2 linear; lift 0.05 em (0.10 bg vocals) over max(1000, duration) × activeness.
- Emphasis: words ≥ 1000 ms, 2–7 graphemes, explicit duration only; amount = min(1.2, f(du/2000)·0.6), glow = min(0.8, f(du/3000)·0.5), f(v) = √v if v > 1 else v³; last word ×1.6 amount, ×1.5 glow, ×1.2 duration; scale 1 + e·0.1·amount; push −e·0.03·amount·(N/2 − i) em; rise −e·0.025·amount em; hop 0.05 em from 400 ms early over ×1.4 duration; easings cubic(0.2,0.4,0.58,1) up, cubic(0.3,0,0.58,1) down.
- Layout: 34 sp main, weight 700, line height 1.2059; bg vocals 0.65 em, translation 0.54 em, romanisation 0.64 em; duet inset 15%; anchor 25% of viewport; edge fade top 10% / bottom 12%; text scale relative to 22 sp; blur strength default 1.2.
- Interlude dots: gap ≥ 9 s; expand/collapse 300 ms; breathing 5 s ±0.2; final pulse 1.1 + 0.3·sin² from 1.5 s before the next line; < 3 s skips breathing; dots 0.3 em, 0.15 em apart, unlit alpha 0.3.
- Clock/scroll: backward jitter < 80 ms ignored; jumps > 1000 ms = seek; fling friction 0.733; snap back after 4.5 s idle or 0.5 s + a target change.
- Background: 96 px art → 4 sprites at 1.0/0.80/0.50/0.25 of screen size, blur σ 0.09·S; rotation +0.09, −0.24, −0.18, +0.12 rad/s; orbit 0.75; twist −3.25 over radius 1.0·S; grade saturation 2.75 → contrast 1.9 → brightness 0.7, then black ×0.5 and white +0.05; 30 fps; 1.7 s crossfade on track change; bright-art luma threshold 0.6; iOS: Metal shader, `.plusLighter` for Plus.
- Sync editor (latest Android): white box marks the word being sung (last tapped) with a small spring pop; tapped words fill with the accent from first to last letter (260 ms sweep, RTL right-to-left) and stay; next word plain white; later words dim; undo rewinds a bit; Back 5 s; speed 1/0.75/0.5; reaction offset 100 ms speaker / 180 ms Bluetooth.
