# Inputs for EngineGen.java (Android PreparedLyricsBuilder + LyricsEngine + LyricsClock on the JVM).
# Fields are TAB-separated. In text fields: \t = tab, \n = newline, \s = space (editors strip trailing spaces),
# \\ = backslash; a lone "-" = null; a missing trailing text field = empty text.
#
# Lyrics definitions (used by the builder golden and by scenarios):
#   LYRICS <name>
#   SL <time> <endTime|-> <voiceRole|-> <text>          synced line
#   SW <time> <endTime|-> <startsNewWord 0|1> <word>     a word of the previous SL
#   ST <translation>                                     translation of the previous SL
#   SR <romanization>                                    romanisation of the previous SL
#   PLAIN <line>                                         a plain line
#   DV <id> <role>                                       a voice of Lyrics.document (DVDEFAULT = [Voice()])
#   DL <startMs> <endMs> <voiceId> <text>                a TimedLine of Lyrics.document
#   DS <startMs> <durationMs> <text>                     a TimedSyllable of the previous DL
#   (Documents are built with the model constructors, not the codec, so invalid documents can be tested.)
#   END
#
# Scenarios (engine traces; frames dump the engine state):
#   SCENARIO <name>    NEWENGINE    CONFIG <density> <blurSupported> <blurEnabled> <strength> <reduced>
#   LYRICS-SET <name> <animateIn 0|1>    VIEW <height> <anchor>    HEIGHTS <h>    HEIGHTLIST <h0> <h1> ...
#   HEIGHT <row> <h>    PLAY <0|1>    POS <ms>    OFFSET <ms>    STEPNS <ns>
#   FRAME    ADV <ms> <dumpStride>    GAP <ms>    REBASE    RESET    MARKSEEK
#   DRAGSTART    DRAG <dy>    DRAGEND <v>    TAP <line>    SCROLLBY <dy>
#   ENDSCENARIO
# Frames: STEPNS-long frames (default 16 ms); the player position advances with the frame clock while playing and
# is read as whole milliseconds (playerNanos / 1e6). GAP moves only the frame clock (wall time without frames).
