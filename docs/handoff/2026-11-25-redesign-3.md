# Redesign batch 3 (iOS), 2026-11-25

Branch `redesign-3` (cut from `origin/redesign-2`, which has batch 2 and its kit). The port of Android's redesign batch 3 (Android
branch `redesign-2`, commits 5126f6b, c2028f9, 58334a6; `handoff/2026-11-25-redesign-2.md` › Batch 3): Home, the mix pages, Endless
Listening's intro, station and Ask the host. Android's layout, sizes, order, spacing and copy; Material swapped for Liquid Glass
(docs/design.md › Redesign batch 3). Not run on a phone: Hoa tests the build.

## What changed

- **Wordplay** `Packages/PixlCore/Sources/PixlLibrary/HomeWordplay.swift` (pure, Android's constants and salts), tests
  `Tests/PixlLibraryTests/HomeWordplayTests.swift` (Android's 7 + 2). The lines: `App/Features/Home/HomeRedesignStrings.swift`
  (also every other batch-3 string: mix page, intro, station, host).
- **Home** `HomeView.swift` (rewritten) + `HomeRedesign.swift` (header, collapsed header, `TwoToneTitle`, section header, Your mix
  hero, Endless pill, mix squares / row / grid, Rewind grid, Fresh row, Ask Taizo card, footer links). Ids kept: `screen.home`,
  `home.greeting`, `home.settings`, `home.jobs`, `ai.taizo.home`; new `home.yourMix(.play)`, `home.endless`, `home.mix.<id>`,
  `home.askTaizoCard`, `home.link.<id>`. The old top bar (Beta / changelog), greeting card, quick actions, chips, Your Mix shelf and
  Recently played carousel are no longer drawn (their types stay in `HomeSections.swift` / `HomePlanSections.swift`); What's new and
  About the beta are footer links. UI tests pin the greeting's clock (18:30, day 20 000).
- **Mix page** `Mixes/MixPage.swift` (`MixPageHero`, `MixPageTopButtons`, `MixPageText`); `MixScreens.swift` (`MixScreen` now takes
  tone / tag / title / remix / showsMore), `MixDetailView.swift`. Save opens `AddToPlaylistSheet` with every song; Daily's More is the
  AI playlist sheet; Daily's Remix is `HomeStore.regenerateDailyMix`, Your's `regenerateYourMix`. First Listen's weekly note is the
  "Why these?" text.
- **Endless intro** `Brain/EndlessIntroView.swift` (rewritten). "Not now" is gone (Close / Skip, like Android). Start / Skip start the
  station (if not running) and replace the cover with the station. From the station's options, Close goes back to the station
  (`EndlessState.introReturnsToStation`).
- **Endless station** `Brain/EndlessStationView.swift`, cover `AppCover.endlessStation` (+ demo screen `endlessStation`;
  `endlessIntro` is a demo screen too). Notes come from `SetNoteMemo` exactly like the player's line; the island line is
  `HostFacts.islandOf` of the current song. The host sheet is presented by the station itself (a root sheet cannot show over a
  cover); `EndlessState.setPendingHostRequest(chip:voice:)` passes the quick ask / the mic once.
- **Ask the host** `AI/TaisChatSheet.swift` host mode (header, now-playing strip, empty hint, tertiary input with the infinity pill,
  pending chip / voice), `AI/TaizoViews.swift` (`\.taizoHost` environment: host badge + "Host" on answers),
  `Brain/EndlessHostViews.swift` (`HostChipsRow` outlined 40 pt, `HostBadge`, `HostSheetHeader`, `HostNowPlayingStrip`,
  `OnAirLabel`, `StationProgressLine`, `HostEmptyState`).
- docs: parity.md › Redesign batch 3, design.md › Redesign batch 3, test-parity.md (HomeWordplayTests).
